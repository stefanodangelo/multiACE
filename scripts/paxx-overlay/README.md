# multiACE PAXX overlay

multiACE @VERSION@ (build `@TAG@`)

This folder is a drop-in overlay for the
[PAXX SnapmakerU1-Extended-Firmware](https://github.com/paxx12-snapmaker-u1/SnapmakerU1-Extended-Firmware)
build system. It adds multiACE support to a PAXX firmware image.

Generated by `scripts/build-paxx-mod.sh` — do not hand-edit a built copy;
edit the source tree or `scripts/paxx-overlay/` and rebuild.

## Usage

1. Clone or fork the PAXX firmware repo.
2. Copy this `40-feature-multiace/` directory into
   `overlays/firmware-extended/40-feature-multiace/` of your PAXX fork
   (or let the builder do it: `build-paxx-mod.sh --into <paxx-fork>`).
3. From the PAXX fork root, with Docker running:
   ```sh
   ./dev.sh make tools
   ./dev.sh make firmware
   ./dev.sh make build PROFILE=extended OUTPUT_FILE=firmware/U1_extended.bin
   ```
4. `firmware/U1_extended.bin` includes multiACE. That is the file you open
   from the printer's own update screen.

## What's in the image

- Klipper extras (`ace.py`, protocol handlers, tip forming, ACE feed and
  switch sensors) at `/home/lava/klipper/klippy/extras/`
- Extruder kinematics at `/home/lava/klipper/klippy/kinematics/`
- Boot hooks `S54`–`S59`: tweak symlink, `ace.cfg` merge-refresh, TRSYNC
  mask, tools sync, mode swap, Klipper page-cache prewarm
- `[include extended/ace.cfg]` wired into `printer.cfg` via PAXX's
  firmware-config tweak system — toggleable in the PAXX UI, including a
  Reset/Uninstall entry for flasher users with no SSH
- The full multiACE source bundle under `/home/lava/multiace/`
- The web service pre-staged at `/home/lava/multiace_web/` with its
  dependencies vendored as aarch64 wheels

User state (`ace_vars.cfg`, `materials.json`, saved loadouts) is
deliberately **not** shipped. PAXX mirrors `firmware-config/extended/` into
`printer_data` on every boot, so a shipped copy would overwrite the user's
tuning each time the printer starts. Those files are created at first run.

## Web UI

Reach it at `http://<printer-ip>/multiace/`. If the service did not come up,
re-run the installer over SSH:

```sh
ssh root@<printer> 'bash /home/lava/multiace/install_web.sh'
```

To remove it later:

```sh
ssh root@<printer> 'bash /home/lava/multiace/install_web.sh --remove'
```
